I am sticky position.

position: sticky; in CSS is a positioning property that works as a mix of relative and fixed positioning. At first, the element behaves like relative, meaning it stays in its normal position in the page layout. But when you scroll and the element reaches a specific point (for example, top: 0), it becomes “sticky” and stays fixed at that position on the screen while the rest of the content continues to scroll. To use it, you must define at least one value like top, bottom, left, or right, otherwise it will not work. Sticky elements only work within their parent container, so they stop sticking when the container ends. This property is commonly used for navigation bars, headers, or section titles so that important information remains visible as the user scrolls.
